# 📐 מתמטיקה ט׳ — לומדה אדפטיבית

ספר לימוד דיגיטלי אדפטיבי לנושא **כפל מקוצר ופירוק לגורמים**, עם מנוע מתמטי
דטרמיניסטי, מודל שליטה (BKT), אבחון תפיסות מוטעות, ומורה פרטי מבוסס Claude.

---

## עקרון התכנון המרכזי

**ה-AI לא עושה מתמטיקה. הוא רק מסביר.**

| מה | מי עושה את זה | למה |
|---|---|---|
| יצירת תרגילים | קוד פרמטרי עם seed | תרגיל ניתן לשחזור, והתשובה הנכונה ידועה בוודאות |
| בדיקת תשובות | מנוע סימבולי (פולינומים עם מקדמים רציונליים מדויקים) | שקילות אלגברית מוכחת, לא הערכה |
| אבחון הטעות | השוואה לתשובות שחושבו מראש לכל תפיסה מוטעית | התאמה מדויקת, לא ניחוש |
| החלטה מה להגיש הלאה | מפת ידע + מודל BKT | שקוף וניתן לכיול |
| **ניסוח הרמז/ההסבר** | **Claude** | זה מה שמודל שפה באמת טוב בו |

התוצאה: מודל שפה לא יכול לקבוע שתשובה שגויה היא נכונה, לא יכול להמציא נוסחה
שגויה כתשובה, והעלות בטוקנים נמוכה (רק ניסוח, לא חישוב).

## הרצה מקומית מיידית (ללא שרת)

הפרויקט הוא HTML/CSS/JS טהור — **אין שלב בנייה, אין npm, אין תלויות**. צריך רק
שרת HTTP מקומי, כי הדפדפן חוסם ES Modules בפרוטוקול `file://` (פתיחת
`index.html` בלחיצה כפולה לא תעבוד).

מתוך תיקיית הפרויקט:

```bash
py -m http.server 8125
```

ואז לפתוח <http://localhost:8125>.

יש מצב פיתוח מקומי שמדמה את ה-API באמצעות `localStorage`, כך שהלומדה עובדת
במלואה בלי לפרוס שום דבר. משתמשים:

| תפקיד | שם משתמש | סיסמה |
|---|---|---|
| מורה | `admin` | `admin123` |
| תלמיד/ה | `demo` | `demo1234` |

במצב הזה **המורה הפרטי מושבת** (אין מפתח API). התרגול, האבחון והמעקב עובדים
במלואם; רק ניסוח הרמזים חסר.

## העלאה ל-GitHub והרצה משם

```bash
git remote add origin https://github.com/<שם-המשתמש>/math9-adaptive.git
git branch -M main
git push -u origin main
```

> **שם התיקייה המקומית ושם הריפו הם שני דברים נפרדים.** גיט לא שולח את שם
> התיקייה, ולכן היא יכולה להיות בעברית. שם הריפו לעומת זאת נשאר `math9-adaptive`
> באנגלית — הוא הופך לכתובת ה-URL, ושם עברי עם רווח ומקף היה מקודד לרצף
> `%D7%A7%D7%91...` ושובר את הקישורים.

מכיוון שאין שלב בנייה, אפשר להריץ את הלומדה ישירות מ-**GitHub Pages**:
**Settings ← Pages ← Source: Deploy from a branch ← main / (root)**.

תוך דקה הלומדה תהיה זמינה ב-`https://<שם-המשתמש>.github.io/math9-adaptive/`,
והבדיקות ב-`.../math9-adaptive/tests/`. במצב הזה כל תלמיד/ה עובד/ת מול
`localStorage` של הדפדפן שלו/ה — מספיק להדגמה ולתרגול עצמאי, אבל **בלי מעקב
כיתתי ובלי מורה פרטי**. לשני אלה צריך לחבר שרת (ראו למטה).

> אין כאן GitHub Actions בכוונה. הבדיקות רצות בדפדפן, והרצה שלהן ב-CI הייתה
> מצריכה להוסיף Node ו-Playwright לפרויקט שכל היופי שלו הוא שאין לו תלויות.
> פתיחת `tests/` בדפדפן נותנת את אותו מידע בדיוק.

## חיבור לשרת (Google Apps Script + Sheets)

1. פתחו [sheets.google.com](https://sheets.google.com) וצרו גיליון חדש.
2. **הרחבות ← Apps Script**, מחקו את התוכן והדביקו את
   [`backend/Code.gs`](backend/Code.gs).
3. **פריסה ← פריסה חדשה**: סוג **Web app**, Execute as **Me**,
   Who has access **Anyone**.
4. העתיקו את ה-Web app URL (מסתיים ב-`/exec`) והדביקו ב-`API_URL` שב-
   [`js/config.js`](js/config.js).
5. פרסמו את התיקייה לכל אירוח סטטי (GitHub Pages, Google Sites, שרת בית הספר).

בפעם הראשונה שקוראים לשרת הוא ייצור אוטומטית את הגיליונות `Users`, `Progress`
ו-`TutorUsage` עם אותם משתמשי ברירת מחדל. **החליפו את סיסמת המורה מיד.**

> **כל שינוי ב-`Code.gs` דורש Deploy ▾ ← ניהול הפריסות ← עיפרון ← גרסה חדשה.**
> אל תיצרו **פריסה חדשה** לעדכון קוד — זה מנפיק כתובת `/exec` אחרת, והכתובת
> שב-`config.js` תהפוך לישנה. עריכת הפריסה הקיימת שומרת על אותה כתובת.

### אימות שהפריסה חיה ושהיא הפרויקט הנכון

פתחו את כתובת ה-`/exec` בדפדפן. `doGet` מחזיר באנר מזהה:

> לומדת מתמטיקה ט׳ - API פעיל. יש לשלוח בקשות POST בלבד.

אם מופיע באנר של פרויקט אחר — הודבקה כתובת שגויה ב-`API_URL`. אם לא מופיע
כלום — הפריסה אינה פעילה או שההרשאה אינה **Anyone**.

### הפעלת המורה הפרטי

**כרגע התכונה כבויה בכוונה**, ונדרשים **שני** מתגים בלתי תלויים כדי להפעיל
אותה — כך שהפעלה בטעות דורשת שני צעדים נפרדים:

1. `TUTOR_ENABLED: true` ב-[`js/config.js`](js/config.js)
2. Script Property בשם `CLAUDE_API_KEY` בצד השרת

כל עוד אחד מהם כבוי, התכונה אינה מוצגת כלל ואין אפילו פניית רשת אליה.

בעורך Apps Script: **⚙ Project Settings ← Script Properties ← Add property**

| Property | Value |
|---|---|
| `CLAUDE_API_KEY` | המפתח שלכם מ-<https://console.anthropic.com> |

המפתח נשמר בצד השרת בלבד ולעולם לא נשלח לדפדפן. אפשר לבדוק שהוא עובד
בהרצה ידנית של הפונקציה `testTutor` מעורך הסקריפטים (Execution log).

**מודל:** `claude-opus-5`, עם `effort: low` — הבקשה היא ניסוח רמז קצר, לא
בעיה שדורשת חשיבה עמוקה. הנחיית המערכת מסומנת ב-`cache_control`, כך שהיא
נקראת מהמטמון בכל קריאה שאחרי הראשונה (כעשירית ממחיר טוקן קלט רגיל).

**מכסה יומית.** `TUTOR_DAILY_LIMIT` בראש `Code.gs` (ברירת מחדל 15 שאלות
לתלמיד/ה ליום). הספירה נשמרת בגיליון `TutorUsage` ונאכפת בשרת — הלקוח רק
מציג אותה, ולכן ניקוי `localStorage` אינו עוקף את המגבלה.

**כל שוויון שהמורה הפרטי כותב עובר אימות.** המודל מתבקש לעטוף שוויונות
ב-⟦ ⟧, והלקוח מריץ את שני האגפים דרך אותו מנוע שבודק את התלמידים. שוויון
שנכשל גורר בקשה חוזרת אחת (שאינה נספרת במכסה), ואם גם היא נכשלת התשובה
נחסמת. שוויון שגוי לא מגיע למסך.

## מפת הידע

```
כפל חד-איברים
  └─ חוק הפילוג
       ├─ כפל שני זוגות סוגריים
       │    ├─ ריבוע של סכום ─ ריבוע של הפרש ─┐
       │    └─ מכפלת סכום בהפרש ──┐            ├─ פירוק לריבוע שלם
       └─ הוצאת גורם משותף ───────┼────────────┘
                                  ├─ פירוק הפרש ריבועים ─┐
                                  └─ פירוק טרינום ───────┤
                                                         └─ פירוק משולב
                                                              ├─ צמצום שברים אלגבריים

```

מיומנות נפתחת רק כשכל קדם-הדרישות שלה מעל 0.70, ונחשבת נשלטת מעל 0.90.
המערכת מציגה לתלמיד בפירוש איזו קדם-דרישה חסרה — לא רק "נעול".

סדר הבחירה של המיומנות הבאה:
1. תיקון תפיסה מוטעית פעילה (עוצמה מעל 0.45)
2. המיומנות הפתוחה שהכי קרובה לשליטה — אזור ההתפתחות הקרובה
3. אם הכל נשלט — חזרה על החלשה ביותר

## הרחבה ליחידות נוספות

היחידה כולה מוגדרת בארבעה קבצים, ואין קוד ספציפי-לנושא מחוצה להם:

1. `js/curriculum/skills.js` — הוסיפו מיומנויות וקדם-דרישות
2. `js/curriculum/lessons.js` — כתבו את ההסבר
3. `js/curriculum/generators.js` — גנרטור שמחזיר `{prompt, exprText, mode, target, answerText, rule, wrongs}`
4. `js/curriculum/misconceptions.js` — הוסיפו את התפיסות המוטעות החדשות

הבדיקות ב-`tests/` יסרקו אוטומטית כל מיומנות חדשה ויתריעו אם התוכן שבור.

המנוע המתמטי כבר תומך בפולינומים רב-משתניים, שברים אלגבריים ופתרון משוואות,
כך שיחידות כמו "משוואות ריבועיות" או "פונקציה לינארית" דורשות תוכן בלבד.

## אבטחה — הערה חשובה

הסיסמאות נשמרות כגיבוב SHA-256 (לא כטקסט גלוי) והתעבורה מוצפנת ב-HTTPS. עם
זאת, זהו אימות פשוט המתאים לכלי כיתתי פנימי: אין salting, אין הגבלת קצב
ניסיונות, ואין ניהול הרשאות מתקדם. אין לאחסן כאן מידע רגיש.
